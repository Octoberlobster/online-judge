## 🚀 快速使用步驟

### 方法一：直接使用範例檔案
1. 下載任一範例 CSV 檔案
2. 登入管理員介面 `/admin/`
3. 點擊 "題目" → "CSV 匯入助手"
4. 上傳檔案並預覽
5. 確認匯入

### 方法二：修改範例檔案
1. 複製 `simple_sample.csv` 為新檔案
2. 修改題目內容為您需要的內容
3. 保存並匯入

### 方法三：從範例學習格式
1. 參考 `CSV_FORMAT_GUIDE.md` 了解格式
2. 查看範例檔案學習寫法
3. 創建您自己的 CSV 檔案
